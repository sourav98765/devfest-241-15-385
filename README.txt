Tender Document Package Builder (practice copy)
================================================
Files
  index.html      Working app (needs internet once to load pdf-lib and the Bangla font)
  ui-mockup.html  Clickable design mockup with sample data only

How to run
  Double-click index.html and open it in Google Chrome.
  Or host it free: drag this folder to netlify.com/drop or upload to GitHub Pages.

How to test (short)
  1. Load sample-pack/requirements.json
  2. Upload all PDFs from sample-pack/documents/
  3. Match files, enter expiry dates, check statuses
  4. Generate and download T-2026-0417_Package.pdf (expect 16 pages with footers)
